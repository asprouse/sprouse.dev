# Code of conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Treat people with respect. No harassment, no slurs, no personal attacks.
- Argue ideas, not people.
- Assume good faith; clarify before escalating.
- If you see a violation, email **andrew@sprouse.dev**.

## Enforcement

Reports are handled privately. Consequences scale with severity, from a private warning to a permanent ban from the project. The maintainer's decision is final.
