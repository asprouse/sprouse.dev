## Role Overview

Titan is looking for a Principal Full Stack Engineer who can ship end-to-end features that span web and mobile surfaces. You'll partner closely with Product, Design, and Backend teams to deliver seamless user experiences across both React (web) and React Native (mobile) applications. The ideal candidate thrives on solving real, user-facing problems with elegant design and engineering excellence.

## Core Responsibilities

- Build and maintain customer-facing products using React (web) and React Native (mobile)
- Implement features end-to-end: frontend UI, backend API integration, data management, and performance optimization
- Collaborate with product designers to create intuitive, responsive UX across multiple platforms
- Identify opportunities to reuse components and unify shared UI patterns and tooling
- Ensure stability and high performance on both web and mobile through testing, metrics, and monitoring
- Contribute to backend endpoints where needed to support frontend features
- Advocate for scalable front-end architecture and clean, maintainable code

## Qualifications

- 6+ years of professional experience building full stack applications
- Expert in JavaScript/TypeScript with hands-on experience in React and React Native
- Familiarity with mobile-first design principles and web/mobile performance considerations
- Experience integrating with backend services, RESTful APIs, and real-time data updates
- Comfortable operating across frontend and backend boundaries to ship cohesive products
- Excellent communication skills and ability to partner with product and design teams

## What Makes You Stand Out

- Contributions to React or React Native open-source libraries
- Experience in fintech or regulated systems with strict reliability expectations
- Past work on consumer apps with rapid release cadences
- Thought leadership on frontend architecture and tooling
